    How Dijkstra's Algorithm Works

    Idea

    Dijkstra's algorithm finds the shortest path from a source node to every other node in a graph with non-negative edge weights. It greedily picks the unvisited node with the smallest known distance and "relaxes" its neighbours.

    Steps

    1. Set distance of source = 0, all others = ∞.
    2. Pick the unvisited node u with the smallest distance.
    3. For each neighbour v: if dist[u] + w(u,v) < dist[v], update dist[v] and set prev[v] = u.
    4. Mark u visited. Repeat until the destination is visited or no nodes remain.
    5. Rebuild the path by following prev from destination back to source.

    Complexity

    With a binary min-heap priority queue (used here): O((V + E) log V), where V = nodes and E = edges. Space: O(V).
